# Outputs

The agent writes its results to `agent_output/`, including `efficiency_report.md`.

| Output | Content |
|---|---|
| Efficiency report | Diagnosis of inefficiencies, quantified in € |
| Production plan | Volumes per line and product over the horizon |
| Schedule | Time-phased schedule |
| Reasoning trace | Steps and tool calls the agent made |
| Executive narrative | Optional, LLM-generated summary |

The same outputs are visible in the dashboard's **:robot: Agent** tab.
