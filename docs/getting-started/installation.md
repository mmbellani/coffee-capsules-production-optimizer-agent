# Installation

## Prerequisites

- Python 3.10+ (recommended)
- Git
- The synthetic coffee-capsule dataset in Parquet format

## Clone the repository

```bash
git clone https://github.com/mmbellani/coffee-capsules-production-optimizer-agent.git
cd coffee-capsules-production-optimizer-agent
```

## Create a virtual environment

=== "Windows (PowerShell)"

    ```powershell
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    ```

=== "macOS / Linux"

    ```bash
    python -m venv .venv
    source .venv/bin/activate
    ```

## Install dependencies

```bash
pip install -r requirements.txt
```
