## Suggested demo script (≈5 minutes)

| # | Step | Message |
|---|---|---|
| 1 | **Overview tab** | "A year of minute-level data from 51 machines — here's how the plant performs." |
| 2 | **Reliability & Downtime** | "A few causes explain most downtime — the Pareto makes it obvious." |
| 3 | **Predictive Maintenance** | "We can see which machines are degrading before they fail." |
| 4 | **Agent tab → Run** | "Now the agent does the analyst's job: diagnose, quantify in €, plan." |
| 5 | **Plan & trace** | "A feasible plan, with a transparent reasoning trace." |
| 6 | **Narrative** | "And an executive summary — numbers stay deterministic." |

## Key messages

- From **data** to **decisions**: analytics → € impact → plan.
- **Deterministic core, LLM as narrator** — trustworthy and reproducible.
- **Self-contained** — DuckDB + Parquet, no infrastructure needed.
